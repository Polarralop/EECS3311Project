# Sample data

Safe sample story sessions for trying the app without generating a scenario first.
Files here must never contain API keys or real personal data.

- `sample-ashfall.json`: lore (two pinned entries) and three characters with relationships, no scenario or turns yet. Copy it into your save folder (`saves/` by default) and load `sample-ashfall`.

The format is the one `JsonSessionRepository` writes: one JSON object per story, named `<id>.json`.
